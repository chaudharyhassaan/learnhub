# LearnHub frontend

Run these commands from this folder in PowerShell.

- `npm.cmd install` installs the frontend dependencies.
- `npm.cmd run dev` serves the React app locally.
- `npm.cmd run build` creates the production site in `dist/`.
- `npm.cmd run lint` checks the JavaScript and JSX.

The pages currently show placeholder headings. Session restoration uses the backend API.
Set `VITE_API_URL` to the backend URL including its `/api` suffix.
